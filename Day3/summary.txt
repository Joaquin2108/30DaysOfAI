For today's challenge, our goal is to call a Snowflake Cortex LLM using the OpenAI-compatible REST API.
We'll build a Streamlit app that lets a user select a model, enter a prompt, and then stream the response
back in real-time.

------------------------------------
Problem

You work as a data analyst at a company whose data is stored in Snowflake. Business users need a simple interface to explore a table without writing SQL.

Build a Streamlit app that:

Connects to Snowflake.
Lets the user select a database/schema/table.
Displays basic information about the selected table.
Shows a preview of the data.
Calculates basic statistics.
Lets the user select columns to visualize.
Runs SQL queries generated by your application.

The important difference from the previous challenge:

We're using Snowflake as the data warehouse, not Snowflake Cortex.
